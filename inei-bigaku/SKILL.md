# 陰翳美学（Shadowism）画風変換

> 美は物そのものではなく、物と物とが作る陰翳のあや、明暗にある——谷崎潤一郎『陰翳礼讃』の趣意

このスキルの仕事は、写真を「暗くする」ことではない。三つの操作で画面をつくり直すことである。

1. **引き算**：余計なものを闇に呑ませ、視線のアンカーをひとつだけ残す
2. **刺点**：果てしない闇の中に、息を呑むような一点の微光を置く
3. **闇の厚み**：闇を空っぽにせず、階調と温度で満たす

露出を下げて暖色フィルターをかけただけの画像は、「露出不足の写真」にしかならない。陰翳は、**何を消し、どこに一点の光を置くか**という設計から生まれる。

---

## 1. 写真を読む（キュレーション）

生成の前に、熟練の目利きのように写真を見て、次を決める。

### ① 構図の浄化 —— 何を残し、何を闇に返すか
- 写真の中から**視線のアンカーをひとつ**選ぶ。急須と茶杯が六つ並んだ商品写真なら急須ひとつ（あるいは茶杯ひとつ）、大勢が写った写真なら一人の横顔と手。
- ほかの物は闇に呑ませる。完全に消すのではなく、輪郭がかろうじて闇の奥に感じられる程度に沈める。主と従の区別を闇が溶かしてくれる。
- **裁ち切り（クロップ）は積極的に使ってよい。** 元写真の構図が散漫なら、アンカーに寄ったクローズアップを主案にする。元写真の構図に忠実であることより、陰翳の画面として成立することの方が大切だからである。
- ただし、ユーザーが「構図はそのままで」と明言した場合は主題と構図を保つ。そのときも周辺は闇に沈めてよい。人物写真は扱いが大きく異なるので §4「人物の陰翳」に従う。

### ② 刺点（Punctum）—— 闇の中の一点の息
画面には、次のうち**少なくともひとつ**を必ず置く。これがない暗さは、ただの「死んだ黒」で、沈んで重いだけの画になる。

| 刺点 | 具体例 |
|---|---|
| **金・銅の沈んだ微光** | 急須の縁、金屏風、真鍮の取っ手、器の金継ぎ。闇の中で一筋だけ鈍く光を拾う |
| **動く気韻** | 湯気、線香の煙、蝋燭の揺らぎ。側光を受けて幽かに白く浮かぶ |
| **半透明の透光** | 障子紙、磁器・玉石の薄い縁、耳や指先の肌、茶や酒の液面。光が内側に籠もり、物自体がほの明るく発光する |

写真にふさわしい刺点がなければ、**光・湯気・煙だけは生み出してよい**（熱い茶から湯気を立たせる、器の縁に光を拾わせる）。ただし物を描き足すことはしない。刺点は画面にひとつ、多くても主従のあるふたつまで。刺点が増えるほど、闇の広さが死ぬ。

### ③ 光源 —— 原則ひとつ
障子越しの鈍い外光、蝋燭・行灯の小さな炎、窓から床を這う夕方の斜光、夜の街の一灯など。光源がひとつに読めると影の向きが揃い、画面が静まる。刺点は、この光源が触れる場所に置く。

### ④ 境界（二つの美の方向）
同じ写真でも、陰翳には大きく二つの方向がある。

| | 境界一【残光・清寂】 | 境界二【金幽・絢爛】 |
|---|---|---|
| 気分 | 侘び、孤独、静けさ、余白 | 深遠、気品、艶、儀式性 |
| 光 | 障子越し・天窓からの微弱な冷たい外光（4500〜5500K、低彩度） | 蝋燭・燭台の一点光（1800〜2000K） |
| 素材 | 素焼き、土、灰釉、古い木、和紙、麻 | 黒漆、金箔・金蒔絵、朱漆、絹、真鍮 |
| 刺点 | 湯気、障子の透光、器の縁の白い照り | 金の縁の一筋の輝き、揺れる燭影 |
| 闇の色 | 墨、藍鼠、灰 | 黒漆、羊羹色、焦茶 |

ユーザーの言葉から方向が読めればそれに従う（「侘び寂び」「静かに」→境界一、「蝋燭」「金」「豪華に」→境界二）。読めなければ、**二つの境界をそれぞれ生成して並べて見せる**。見比べることで、ユーザー自身が自分の求める陰翳を発見できるからである。

## 2. 文学を光学に翻訳する

陰翳の語彙（手沢、羊羹色、澱んだ闇）は、このスキルを使うモデルが美を理解するためのものである。一方、画像モデルは光学とレンダリングの言葉で訓練されているので、詩的な形容詞だけを渡すと「露出を下げて黄ばませる」としか解釈しない。**生成の指示文では、必ず次のように物理的・撮影的な言葉に翻訳する。**

| 陰翳の語彙 | 光学・レンダリングの言葉 |
|---|---|
| 羊羹色・玉の温潤（光を吸い込み、内に籠もらせる） | subsurface scattering, light penetrating a few millimeters into the material, translucent depth |
| 手沢・沈んだ照り | high specular roughness, micro-scratched matte patina, muted Fresnel reflection, satin sheen |
| 光が闇から滲み出る | inverse-square light falloff, single practical light source, soft rim light, 1800K blackbody color temperature |
| 澱んだ闇（空っぽではない闇） | low-key exposure with retained shadow detail, deep shadows lifted just above black, no crushed blacks |
| 障子の透光 | large diffused backlit paper panel, self-luminous translucent surface, soft wrap light |
| 金屏風の暗がりの輝き | tarnished gold leaf catching a single grazing specular highlight, anisotropic metallic reflection in darkness |
| 湯気の気韻 | delicate wisps of steam side-lit against a black background, volumetric light |
| 余白は闇 | negative space filled with deep shadow, subject off-center, heavy vignetting motivated by the light source |
| 時間の厚み | fine film grain, Kodak Vision3 500T, slight halation around the light |

より詳しい対照と色・光のパラメータは `references/optics-and-palette.md` にある。

## 3. 画面の原則

### 明度 —— 闇に階調を
- 画面の7〜8割を深い暗部と暗い中間調が占める。ただし純黒に潰さず、目が慣れると何かが見えてくる階調を残す。
- ハイライトは小さく鈍く暖かく（蜜色・象牙色）。白飛びやぎらついた鏡面反射は陰翳を壊す。
- 暗い画面の中でも、刺点の周辺だけは**局所的なコントラストをはっきり持たせる**。全体は静か、一点だけは鮮やか。この対比が画面の息づかいになる。

### 色
- 闇：黒漆、墨、煤竹、藍鼠、羊羹色。中間：飴色、焦茶、枯緑青、錆朱。光：燻し金、蜜色、象牙、生成り。
- 全体の彩度は低い。色は「見える」ものではなく「気配」として置く。光源の色温度は一種類に揃える。

### 質感
- 新品の光沢ではなく、年月と人の手が生んだ艶消しの照り。和紙の繊維、古い木目、ごく細かなフィルム粒子。デジタルの滑らかさは時間の厚みを消してしまう。

### 現代の写真を扱うとき
カフェ、都会の部屋、夜の街角、スマホ写真も対象になる。
- 天井照明・蛍光灯・ネオンを消し、光源を一灯のタングステン光（窓の灯り、卓上ランプ、街灯ひとつ）に置き換える。
- ガラス・金属・プラスチックの反射を曇らせる。看板や文字は闇に溶かして読めなくする。
- 夜の街なら、雨に濡れた路面に一灯が長く映り込む画面は陰翳と相性がよい。
- 視覚的な手本は `references/masters.md` を参照する（宮川一夫、杜可風（王家衛作品）、ハンマースホイ、杉本博司など）。ただし手本から借りるのは「一灯・濡れた反射・深い緑と焦茶の闇」という光の扱いだけで、高彩度のネオンや硬い日差しは借りない。

**着物、鳥居、提灯、桜など、和風の小道具を描き足さない。** 陰翳は記号ではなく、光と闇の関係そのものである。

## 4. 人物の陰翳

人物は、陰翳のもっとも難しい題材である。器には表情がないので、闇はそれに静けさと深みを与える。しかし人は体温と表情を持っているため、光を剥ぎ取りすぎると生気を失う。画像モデルにとって「暗がりに浮かぶ青白い顔」は、幽玄よりもホラー（怨霊、生首、不気味の谷）に直結している。人物では、物と同じ手順をそのまま当てはめてはいけない。

谷崎も人を闇の中に描いたが、それは人を主人公として照らし出すのではなく、**暗い空間の一部として**見るやり方だった。人物の陰翳は、この見方に立つ。視線を「顔立ちの識別」から「気配・輪郭・しぐさ」へ移し、肖像写真ではなく**映画の一場面**として撮り直す。

### 最初にひとこと、期待を合わせる
人物写真を受け取ったら、目利きの一言の中で「美肌の肖像ではなく、静かな映画の一場面のような画になります」と伝える。証明写真や、明るく綺麗に写りたいという依頼（「盛って」「美肌に」など）とは、陰翳の美学は目的が逆である。その場合は、陰翳の強さを抑えた版を提案するか、このスキルの画風が合わないことを率直に伝える。

### 生きていることを示す五つの条件
暗くても生きた人に見えるよう、次を必ず満たす。

1. **肌に体温を**：光は蜜色・琥珀色（1800〜2500K）。耳のふち、頬骨、鼻の先、指先に、血の色が透ける温かさ（次表面散乱）。青白い肌、灰色の肌、冷たい光は使わない。
2. **影の側を潰さない**：顔の影の側も、目鼻の形が読める程度の階調を残す（光の側の1/4〜1/8程度の明るさ）。顔の半分を真っ黒にすると、顔が欠けて見える。
3. **身体を闇に溶かしつつ、消さない**：衣のひだや肩の形が、闇の中でかすかに読めるようにする。首から下を完全な闇にするのは、生首に見える一番の原因である。ただし輪郭を光の線で縁取るのではなく、影の側の輪郭は背景の闇に溶かす（次の「人と空間を一体にする」）。
4. **目に一点の光**：瞳に小さなキャッチライトをひとつ。これが生きている人の最も強い合図になる（人物の刺点にもなる）。
5. **穏やかな表情の気分**：沈思、安らぎ、優しさ。表情そのものは元写真のまま変えず、光と色で「静かさ」を与える。怯え、悲しみ、虚ろな目は避ける。

### 肌に質感の指示を当てない
§3の「手沢」「粒子」「艶消しの照り」は物のための指示である。肌に当てると、染み・汚れ・荒れた肌に見える。肌は**なめらかで温かいまま**にし、粒子は画面全体にごく薄く、特に顔の上では目立たせない。手沢や経年の質感は、衣・器・木・畳に置く。

### 人と空間を一体にする
人物を変えまいとすると、画像モデルは人物の部分を「触れてはいけない領域」として扱い、元写真の光のまま残してしまう。その結果、光を変えた背景の上に人物を貼り付けたような、**切り抜き合成の画**になる。陰翳では人は空間の一部でなければならないので、これは致命的である。

- **保つのは顔立ちであって、光ではない。** 骨格・目鼻・表情・年齢・髪型は保つ。しかし人物に当たる光・影・色は、背景と同じく完全に描き直す。指示文でも「顔を変えるな」ではなく「顔立ちは保ち、光は部屋と同じ光で描き直せ」と書き分ける。
- **一つの光が、人と部屋を同時に照らす。** 光源を空間の中の具体的な位置に置き、その光が壁・床・卓と人物の頬に、同じ向き・同じ色・同じ減衰で届くようにする。
- **影の側の輪郭は、背景に溶かす。** 人物の影の側と、その後ろの背景を同じ暗さにそろえ、境目が見えなくなるようにする（ロスト・エッジ）。輪郭がはっきり見えるのは、光の当たる側のごく一部だけでよい。人物を光の線で縁取ると、切り抜きに見える。
- **人と空間の間に光の行き来をつくる。** 人物が床や壁に落とす影、手や器の下の接地影、暖かい壁から影の側の頬に返る弱い照り返し、人と卓上の器が同じ光だまりの中にあること。
- **同じ空気で包む。** 粒子・色調・ぼけ・かすかな霞を、人物にも背景にも同じように掛ける。
- **背景はなるべく元の空間を照らし直す。** 背景を別の和室などに差し替えると、合成に見えやすい。差し替える場合は、新しい空間の光が人物にどう当たるかまで書く。
- **二段階で作る。** 一度で一体化と同一性の両方を得るのは難しい。まず人物ごと空間全体を一つの光で描き直し（顔立ちが多少揺れてもよい）、次に「光と空気はこのまま、顔立ちだけを元写真に合わせて戻す」と指示する。

似ていることと、空間に溶けていることは、少し引っ張り合う関係にある。その兼ね合いは目利きの一言でユーザーに伝え、どちらを優先するか選べるようにする。

### 人物の三つの撮り方
| 撮り方 | 内容 | いつ使うか |
|---|---|---|
| **A. 光だけを変える**（既定） | ポーズ・構図・顔立ちはそのまま。部屋ごと一つの暖かい光で照らし直し、人物の影の側を背景の闇に溶かす | 家族や本人の写真など、その人らしさに意味があるとき。「似ていること」が最優先 |
| **B. 寄りの切り取り** | 伏せた瞼と頬、茶碗を包む手、うなじと襟元など、一部分だけに寄る | 元写真にその部分が写っていて、画としての強さを優先したいとき |
| **C. 映画の一場面として再構成** | 横顔（鼻筋と唇の輪郭に暖かい光の線）、窓辺や屏風のそばの後ろ姿（ハンマースホイ式）、器を扱うしぐさ | 再解釈モード、またはユーザーが同意したとき。顔立ちの同一性は保証できないと一言添える |

正面を向いた顔のアップを、照明を消しただけで闇に浮かべる画は作らない。それはAを選んだ場合も同じで、Aでは上の五つの条件によって生気を保つ。

光と構図の具体的な言葉、手本、プロンプト雛形は `references/portrait.md` にある。人物が写っている写真では必ず読む。

## 5. 避けるべきもの

| 避けるもの | 理由 |
|---|---|
| 露出を下げ、暖色フィルターをかけただけの画 | 刺点も引き算もなく、「停電した部屋」にしか見えない |
| 雑多な元構図をそのまま暗くすること | 引き算の美学が足し算の構図に負け、「停電した展示即売会」になる |
| ホラーやゴシックの闇（不気味さ、冷たい青緑） | 陰翳の闇は恐怖ではなく、安らぎと沈思の闇 |
| 闇に浮かぶ青白い顔、首から下のない顔 | 画像モデルには怨霊・生首として読まれる（§4） |
| ノワール的な刃物のようなハードシャドウ | 陰翳の境界は滲みとぼかしで溶ける |
| HDR、過度なシャープネス | すべてを見せようとする明るさの美学は、陰翳の対極にある |
| 光源に根拠のない、機械的なビネット | 加工にしか見えない |
| 和風の記号の追加 | 画面が浅く、観光的になる |

## 6. 出力の流れ

### 画像を生成できる環境（Gemini など）
1. **目利きの一言**（2〜4行）。写真をどう読んだかを、美学の目利きとして率直に書く。例：
   > 元の写真は茶器が六つ並んだ商品撮影で、視線が散っています。急須の注ぎ口と、そこから立つ湯気だけを残し、ほかは闇に預けました。寄りで切り取った版をおすすめします。
2. **生成**：
   - 境界が読み取れない場合は、境界一【残光・清寂】と境界二【金幽・絢爛】を一枚ずつ生成する
   - 構図を大きく裁ち切った場合は、クローズアップ版を主案として出す
   - 指示文は §2 の光学の言葉で書く（雛形は `references/prompt-templates.md`）
3. **自己点検**（下のチェックリスト）。明らかに外れていれば、一度だけ直して再生成する。
4. **一言で締める**。「もう少し闇を深く」「元の構図を残した版も」など、次の一手を一行で添える。長い解説は画面の余韻を壊す。

### 画像を生成できない環境
1. 目利きの一言
2. `references/prompt-templates.md` をもとに、二つの境界それぞれの**画像編集プロンプト**（英語本文と日本語要約）を出す。既定は Gemini 向けで、Midjourney や SD と言われればその雛形を使う。
3. どのツールにどう貼ればよいかを一行で案内する。

### 自己点検チェックリスト
- [ ] 視線のアンカーはひとつに絞れているか（元構図の雑物がそのまま残っていないか）
- [ ] 刺点（金の微光／湯気・煙／透光）が少なくともひとつあり、画面で最も目を引くか
- [ ] 光源はひとつに読め、影の向きが揃っているか
- [ ] 闇に階調があるか（純黒の平板な塊になっていないか）
- [ ] アンカーは闇の中でも確かに見えるか（隠しすぎて何の写真か分からなくなっていないか）
- [ ] ホラーやノワールに寄っていないか。静けさと温度があるか
- [ ] 和風の小道具を足していないか
- [ ] （人物）肌は温かく、影の側も読め、肩や衣が闇の中にかすかに見えるか。目に光があるか。ホラーに見えないか
