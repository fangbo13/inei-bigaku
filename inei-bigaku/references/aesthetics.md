# 陰翳の美学 —— 原理から画面操作へ

『陰翳礼讃』（1933）は、電灯が普及しつつあった時代に、谷崎が日本の住まい・器・食・装いに宿っていた「暗がりの美」を書き留めた随筆である。
ここでは、その原理を画像変換で使える具体的な操作に置き換える。

## 目次
1. 九つの原理
2. モチーフ対照表（谷崎の題材 → 画面での扱い）
3. 題材別の扱い方
4. 画材・表現の置き換え

---

## 1. 九つの原理

| # | 原理 | 画面での操作 |
|---|---|---|
| 1 | **美は物ではなく、陰翳のあやにある** | 主題を明るく描き込むのではなく、主題の周りの影の重なり・濃淡のグラデーションを丁寧に描く |
| 2 | **闇は空虚ではなく、充ちている** | 暗部にかすかな色味（焦げ茶・藍鼠・墨紫）と微細な粒子を残し、「何かがありそう」な密度を持たせる |
| 3 | **光は照らすものではなく、滲むもの** | 光の境界をぼかす。光が物の表面を「撫でる」ように、片側だけに触れさせる |
| 4 | **沈んだ照り（手沢）を尊ぶ** | 新品の光沢・鏡面反射を鈍らせ、長年の手擦れによる柔らかい照りに置き換える |
| 5 | **見えないものが想像を呼ぶ** | 画面の一部（端、奥、物の半分）を意図的に闇に委ねる。すべてを説明しない |
| 6 | **金は暗がりでこそ生きる** | 金・真鍮・金蒔絵は、周りが暗いときに一点だけ弱い光を拾って「ぼうっと」浮かぶように描く |
| 7 | **静けさと瞑想** | 動きの少ない構図、水平・垂直の落ち着いた線、時間が止まったような空気。見る者の呼吸がゆっくりになる画面 |
| 8 | **引き算（余白こそが黒）** | 見せるものを一つに絞り、残りは闇に呑ませる。元写真に物が多いほど、闇の仕事は大きくなる |
| 9 | **闇の中の一点の息（刺点）** | 果てしない闇の中に、金の一筋・湯気・透光のような息を呑む微光を一点だけ置く。これがなければ闇は死んだ黒になる |

## 2. モチーフ対照表

谷崎が随筆で取り上げた題材と、そこから引き出せる画面操作。題材そのものを画面に描き足すのではなく、**その題材が教える「光の扱い方」を写真に適用する**ために使う。

| 谷崎の題材 | そこにある美 | 写真への応用 |
|---|---|---|
| 漆器（黒・茶・朱） | 蝋燭の揺らぐ光の中で、底知れぬ深みと艶が浮かぶ | 暗い面を「のっぺりした黒」ではなく、奥行きのある深い黒茶に。縁だけが細く光を拾う |
| 金蒔絵・金屏風 | 暗い室内の奥で、遠い外光を集めて静かに光る | 金属や黄色系の要素を、闇の中の小さな発光点として扱う |
| 羊羹 | 光を吸い込み、内部に夢のような仄明るさを含む | 半透明のもの（飲み物、果物、肌、磁器）の内部にかすかな光が籠もるように |
| 吸い物椀の闇 | 蓋を取るまで中が見えない、見えないことの愉しみ | 器の内側・部屋の奥・物の陰を深い闇のまま残す |
| 障子 | 外光を濾過し、白く鈍い、ほの明るさに変える | 窓光を柔らかく拡散させ、室内に届く頃にはほぼ消えかけた光にする |
| 床の間 | 奥まった空間に澱む、静かな影 | 画面の奥の空間を最も暗く、最も静かな場所にする |
| 厠（薄暗さ、木の香り、外の気配） | 薄暗がりの中で感覚が研ぎ澄まされる | 明るさを抑え、質感（木目、湿り気）を感じ取れる程度に残す |
| 能・文楽の衣装と肌 | 暗い舞台の上で、顔と手が衣の闇から浮かぶ | 光は顔と手に集めるが、衣の輪郭と肩はかすかに残す（`portrait.md`） |
| 昔の女性の装い（お歯黒、眉墨、暗い衣） | 身体を闇に沈め、顔だけを浮かび上がらせる | **画像では再現しない**（生首・怨霊に読まれる）。肌は青白くせず、蜜色の温かさを保つ |
| 燭台・行灯・蝋燭 | 小さく揺らぐ暖かい光、光の届く範囲の狭さ | 光源の届く範囲を狭く、光の減衰を急にする |
| 古い銀器・錫・翡翠 | 曇り、錆び、濁りに時間の味わいを見る | 金属やガラスの反射をくもらせ、半透明・半艶に |

## 3. 題材別の扱い方

### 伝統的な室内（町家、寺院、旅館、茶室）
- もっとも陰翳と相性がよい。元写真が昼間で明るい場合は、障子越しの夕方の光か、夜の行灯の一灯に置き換える。
- 畳・柱・床の間・欄間の木目は、光の当たる一角だけに残す。天井と部屋の隅は闇に沈める。

### 器・静物・料理・商品写真
- 商品写真やカタログ写真は物が多く、均一に照らされている。ここでは引き算がいちばん効く。器をひとつ（急須なら注ぎ口、茶碗なら縁と内側の闇）に絞り、ほかは闇の奥に沈めるか、画面の外へ裁ち切る。
- 刺点は湯気、金継ぎや縁の金、液面に映る炎が作りやすい。
- 真上からの均一な照明を捨て、横から低く差す一灯に。器の内側と背景を闇に。
- 汁物・茶・酒の水面にだけ、光源が小さく映る。料理の彩りは彩度を落とし、暖色の気配として残す。

### 人物・ポートレート
- 人物は物と同じ手順で扱わない。詳細は `portrait.md` を読む。
- 谷崎の「顔と手だけが闇に浮かぶ」という描写は、画像にそのまま移すと怪談になる。取り入れるのは「人を暗い空間の一部として見る」という見方だけ。
- 肌は温かく、影の側も読め、肩や衣は闇の中にかすかに見え、目には光がある——暗くても生きている人として描く。

### 屋外・風景
- 昼の風景は、夕暮れ〜宵、雨の日、深い木陰、霧の中などへ時間と天候を移す。
- 空は暗く沈め、光は一方向の低い夕光、または家の窓から漏れる灯り一つに。
- 苔、濡れた石、古い木の幹など、湿り気のある質感を闇の中に感じさせる。

### 現代の空間（カフェ、オフィス、都会の部屋、街角）
- 天井照明をすべて消し、窓際の夕光かテーブル上の小さな暖色灯一つに置き換える。
- ガラス・金属・プラスチックの反射を曇らせる。モニターやスマホ画面は消灯か、極めて暗く。
- 看板・文字・ロゴは闇に溶かして読めなくする。
- 夜の街は、雨に濡れた路面に一灯が長く映る画面にすると陰翳と相性がよい。手本は `masters.md` を参照。
- 和の小道具を足さずに陰翳を成立させることが、このスキルの腕の見せどころ。

## 4. 画材・表現の置き換え

写真らしさを離れて、陰翳を画材の質感で表すときの手段。組み合わせすぎず、一つか二つを選ぶ。境界一【残光・清寂】には墨・素焼き・和紙、境界二【金幽・絢爛】には漆絵・金箔・岩絵具が合う。

- **漆絵の質感**：黒漆の地に、金・朱・錆色で光の部分だけが描かれたような画面
- **墨の滲み**：暗部を墨の濃淡とにじみで表現し、光の部分に紙の地色を残す
- **古い日本画（岩絵具）**：くすんだ岩絵具の粒子感、金泥・銀泥の酸化したような鈍い光
- **大胆なクロップ**：主題の一部分だけを切り取り、残りを闇へ。例：人物の手元と茶碗だけ
- **時間の移動**：昼を宵へ、晴れを雨へ、夏を晩秋・冬へ
